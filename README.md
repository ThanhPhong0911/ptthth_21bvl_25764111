# Java I/O Stream Lab

## Cấu trúc thư mục
- src: chứa các file Java
- data: chứa dữ liệu đầu vào và đầu ra

## Các file chính
- src/ConsoleReaderDemo.java: demo nhập dữ liệu từ console
- src/FileReadWriteDemo.java: demo đọc và ghi file
- data/input.txt: file dữ liệu mẫu
- data/output.txt: file đầu ra sẽ được tạo khi chạy demo đọc/ghi file

## Cách chạy
1. Mở terminal trong thư mục gốc project
2. Biên dịch:
   javac src/ConsoleReaderDemo.java
   javac src/FileReadWriteDemo.java
3. Chạy:
   java ConsoleReaderDemo
   java FileReadWriteDemo

> Lưu ý: khi chạy FileReadWriteDemo, cần đảm bảo thư mục data nằm cùng cấp với src.
